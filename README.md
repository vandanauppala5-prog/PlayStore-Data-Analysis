# 📊 Play Store Data Analysis

## 📌 Project Overview
This repository contains six data visualization tasks completed using Python and Jupyter Notebook as part of a Data Analysis internship project. The project analyzes the Google Play Store dataset using data cleaning, filtering, and interactive visualizations.

## 📂 Repository Structure

```
PlayStore-Data-Analysis/
│
├── Task1.ipynb # Bubble Chart
├── Task2.ipynb # Choropleth Map
├── Task3.ipynb # Time Series Line Chart
├── Task4.ipynb # Stacked Area Chart
├── Task5.ipynb # Grouped Bar Chart
├── Task6.ipynb # Dual-Axis Chart
├── Play Store Data.csv
├── UserReviews.csv
└── README.md
```

## 📈 Tasks Completed

### Task 1 – Bubble Chart
- Visualized the relationship between App Size and Average Rating.
- Bubble size represents the number of installs.
- Applied required filters and category translations.

### Task 2 – Choropleth Map
- Created an interactive choropleth map using Plotly.
- Displayed installs for the top app categories with required filtering.

### Task 3 – Time Series Chart
- Analyzed install trends over time.
- Highlighted periods with significant month-over-month growth.

### Task 4 – Stacked Area Chart
- Visualized cumulative installs across app categories.
- Highlighted months with more than 25% growth.

### Task 5 – Grouped Bar Chart
- Compared average ratings and total reviews across the top categories.
- Applied assignment-specific filters.

### Task 6 – Dual-Axis Chart
- Compared Average Installs and Revenue for Free vs Paid apps.
- Applied multiple filtering conditions and dual-axis visualization.
